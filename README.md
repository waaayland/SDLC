## Описание курсового проекта

**UAVLog 1.0** — автономное настольное приложение под Windows 10/11 x64 на языке C++17 с графическим интерфейсом Qt 6.11 (Qt Widgets) и однофайловой локальной СУБД SQLite 3 (режим WAL) для учёта эксплуатации парка беспилотных летательных аппаратов (БЛА):

- учёт типов БЛА, табличных регламентов ТО (≥ 5 видов ТО на тип), паспортов бортов (со штатной полезной нагрузкой), АКБ и операторов с допусками;
- предполётный осмотр по электронным чек-листам (`F-15`) с автоматическим переводом борта в «Неисправен» при критичных замечаниях;
- регистрация полётов с клавиатуры (`Tab` / `Enter` / `Esc`), автоматическим 5-факторным контролем допуска и детерминированным пересчётом налёта, циклов АКБ и остатков до ТО;
- панель предупреждений с настраиваемыми порогами (`10 %` / `7 дн.` / `14 дн.` / `90 %`), формуляр борта (4 вкладки), 5 сводных отчётов (включая «Акт готовности парка к полётам») с экспортом CSV (UTF-8 BOM, `;`), PDF A4 и печатью;
- аутентификация PBKDF2-HMAC-SHA256 (100 000 итераций), RBAC на уровне сервисов (4 роли), автоблокировка сеанса через 15 мин, атомарный журнал аудита `audit_log` и резервное копирование БД `VACUUM INTO`.

Архитектура приложения — четырёхслойная (MVC / Presentation → Application Services → Pure C++17 Domain `uavlog_core` → Infrastructure `uavlog_infra`) по [ADR-0001](docs/decisions/0001-layered-mvc-architecture.md).

## Технологии

- **Язык:** C++17
- **Фреймворк GUI и печати:** Qt 6.11.2 (Qt Widgets, Qt SQL, Qt PrintSupport, Qt Test)
- **СУБД:** SQLite 3 (режим WAL, `foreign_keys = ON`, `synchronous = FULL`)
- **Сборка и тестирование:** CMake, Ninja, MinGW 13.1.0 64-bit, CTest
- **Моделирование:** SysML v2 (ЛР №3), PlantUML UML 2.5 + монохромный рендерер СТП 01–2024 (ЛР №5)

## Сборка, тестирование и запуск UAVLog 1.0

> Из-за ограничений `moc` в Qt 6 путь к каталогу сборки должен содержать только ASCII-символы (по умолчанию `C:\Users\%USERNAME%\QtBuilds\UAVLog`).

1. **Автоматическая сборка и прогон всех 12 тестов CTest:**
   ```bat
   cd project\UAVLog
   build.bat
   ```
2. **Запуск приложения UAVLog 1.0:**
   ```bat
   run.bat
   ```
3. **Демонстрационные учётные записи (создаются автоматически при первом запуске):**
   - `admin` / `Admin123!` — Администратор (Начальник службы)
   - `tech` / `Tech123!` — Техник по ТО
   - `operator` / `Oper123!` — Оператор БЛА
   - `viewer` / `View123!` — Наблюдатель (только чтение)
