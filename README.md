## Описание проекта

Настольное приложение с графическим интерфейсом для генерации паролей.
Пользователь задаёт длину пароля, наборы символов (строчные и прописные
буквы, цифры, специальные символы) и количество паролей. Ввод выполняется
в отдельном диалоговом окне, последние введённые данные запоминаются и
восстанавливаются при повторном вводе. Результат отображается на главной
форме. При некорректных данных выводится сообщение об ошибке.

Архитектура приложения — паттерн MVC с активной моделью.

## Сборка

1. Открыть `project/PasswordGenerator/CMakeLists.txt` в Qt Creator.
2. Выбрать комплект *Desktop Qt 6.11.2 MinGW 64-bit* (генератор Ninja).
3. Собрать и запустить проект (Ctrl+R).
